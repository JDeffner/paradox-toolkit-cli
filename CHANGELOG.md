## 0.2.0 - 2026-10-06

- Distribute `@px-lsp/cli` on npm, `@jdeffner/cli` on GitHub Packages and an installable GitHub release archive. Both registry packages provide `pxtk` and 21 MCP tools.
- Add translation synchronization, safe symbol renaming and precise definition edits through CLI and MCP, with required preview tokens and source-preservation checks.
- Add ordered mod conflict reports using the shared composition policy, with explicit unknown winners and coverage limits.
- Add exact vanilla file or directory-path import and local release staging with `.pxignore`, content hashes and descriptor findings.
- Add migration catalogs, exact-build routes and recipe previews. Local code requires explicit hash trust; workers capture diagnostics and stop on cancellation. Migration plans are not applied.
- Bundle the migration worker and the Toolkit's ignore-pattern dependency in standalone packages, with installed-package and real-client workflow checks.
- Refresh the shared core to support renaming localization declarations and to execute the exact trusted CommonJS recipe bytes. Recheck source inputs during multi-file writes and report interrupted copies explicitly.

## 0.1.0 - 2026-10-05

- Reject unknown MCP input fields, keep help and version output machine-readable with `--json`, and report ignored or malformed CLI arguments.
- Protect writer roots and ancestors against link replacement, and check duplicate definitions through the shared game schema and parser.

- Add release installation steps and a full usability, functionality and verification audit, with known game and platform limits.

- Add saved launcher playset inspection and preview-first game launch through CLI and MCP. Require a reviewed token to start, preserve launcher selection and unrelated load settings, and reject stale previews or an already-running game.
- Add paged source reading through CLI and MCP, with explicit excerpt limits, lossless continuation and saved-file hashes.
- Expose baseline creation through MCP. Report Tiger's explicit game-version incompatibility, preserve its findings, and refuse baselines for incomplete validation.
- Publish MCP output schemas and parameter help, with complete preview-token examples for agents.
- Add preview-first new-mod creation for each supported profile, including descriptor or metadata, starter folders and portable CLI configuration. Preserve existing destinations and reject stale previews.

- Move the CLI into its own repository with independent build, test and package commands. Pin the shared Toolkit packages so development does not require the editor checkout.

- Share portable project rules, per-artifact legacy reads and localization placement with the editor. Protect generated localization and include author defaults in preview and validation snapshots.

- Add previewable create, localization, initialization, formatting, log checkpoint and image preparation commands through CLI and MCP. Reuse game profiles and codecs, preserve saved source files, and reject stale previews and output collisions.
- Add sourced examples and measured templates to inspect, exact reference sites to impact, and explicit structural file selection to validation while retaining whole-mod Tiger checks.

- Add standalone pxtk status, search, inspect, impact and validate commands, local MCP tools, a portable skill, and plugin manifests.
- Include the LSP and game data in the package. Report evidence sources, coverage limits, validation failures and baseline differences.
